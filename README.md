# MogaJet

A polished Next.js prototype for a private-jet charter marketplace/broker.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included

- MogaJet luxury homepage
- Charter search form
- Aircraft filtering and sorting
- Aircraft result cards
- Quote-request modal
- Responsive navigation
- Demo aircraft data

## Production roadmap

1. Replace demo aircraft data with PostgreSQL/Prisma.
2. Add authentication for customers/operators/admins.
3. Connect operator quote workflow.
4. Add airport/aviation data provider.
5. Add Stripe deposits after operator confirmation.
6. Add operator verification and contractual/compliance workflows.
7. Add transactional email and audit logging.

Important: demo prices and availability are illustrative and should not be presented as confirmed charter availability.
